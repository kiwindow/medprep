## 1. きっかけ

`前処理済み_test.xlsx` を開いた User から。

> この「欠損あり_」というものは何を表すのでしょうか。殆どの値が同じ値です

`欠損あり_〇〇` は sklearn の `SimpleImputer(add_indicator=True)` が作る欠測指標で、
**「その値は欠測だったので埋めた」という 0/1 の印**である。

「殆どの値が同じ」に見えたのは、**欠測が少ないから**と、**標準化が掛かっていたから**。

| 列 | 欠測率 | 標準化後 |
|---|---|---|
| `欠損あり_年齢` | 0.5% | 99.5% が **−0.056**、0.5% が **+17.9** |
| `欠損あり_アルブミン(Alb)` | 8% | 92% が **−0.278**、8% が **+3.59** |
| `施設=B院`（ダミー） | — | **0 / 1 のまま** |

★同じ 0/1 の旗なのに、ダミー変数は 0/1 のままで、欠測指標だけ標準化されていた。★
これは設計判断ではなく、**標準化がカテゴリの枝を通らず数値の枝だけを通る**という
置き場所の事故である。

## 2. User の判断

> 欠損ありは、場合によっては意味があるデータの事があり、…残す意義は機械学習の
> 観点からはあります。しかし、多くの場合、単なる入力ミスや意味のない欠損のことが
> あるため、…sheet3として「欠損値の位置」というシートで保存するようにして下さい。

選択肢を示して確認した結果、**「sheet1 から全部外す」** を選択。

## 3. 直し方

### 3.1 sheet3「欠損値の位置」を追加

`前処理済み_*.xlsx` は **3 枚組**になった。

| シート | 中身 |
|---|---|
| 標準化後 | モデルに渡す行列。施設は `施設=B院` のダミー、数値は z 値 |
| 生の値 | 同じ症例・同じ列を、標準化する前の値で |
| **欠損値の位置** | **補完する前に、どこが空欄だったか**を 0/1 で |

最後の列 `欠損数` は、その症例に空欄がいくつあったか。
**ここが大きい行は、症例そのものを疑う手がかりになる。**

実際の出力（400 例）: `欠損数` の分布は `{0: 255, 1: 42, 3: 23}`。
3 が 23 例あるのは、Alb が欠測すると **そこから作る `iCa` と `iCa×P` も同時に
欠測する**ためで、派生指標の欠測が連鎖することがひと目で分かる。

### 3.2 欠損指示子は既定では特徴量にしない

`policy["missing"]["add_indicator"]` の既定を **False** にした。

**情報は 1 つも失われない。** 欠測の位置は「欠損値の位置」シートに残るので、
意味のある欠測だと判断したら、その列だけを結合して特徴量にすればよい。
全列に作らせたいときは `policy={'missing': {'add_indicator': True}}` と明示する
（そのときは従来どおり `欠損あり_〇〇` という読める名前で出る）。

既定で作らなくなったので、**標準化の食い違いも同時に消えた。**
