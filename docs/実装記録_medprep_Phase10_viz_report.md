## 2. 色は「目分量」で決めない

色は最後に決める。まず**そのデータの仕事**で図の形を決め、仕事で色の役割を決める。

| 仕事 | 配色 | medprep での例 |
|---|---|---|
| identity（どれがどれか） | カテゴリ配色（決まった順、循環させない） | 群別の分布、PCA |
| magnitude（大きさ） | 単一色相の明→暗 | 関連の強さ（η² / Cramér's V、0〜1） |
| polarity（符号のある量） | 2 色相 ＋ **灰色の中点** | 相関（−1〜1） |
| state（良し悪し） | 状態色（**ラベルと必ず併記**） | SMD が閾値を超えた印 |

**相関と「関連の強さ」で配色を取り違えてはならない。**
関連の強さに発散配色を当てると、中点の灰色が「関連なし」ではなく
「負の関連」に見える。0〜1 の量に負はない。

配色は検証にかけた（明度帯・彩度の下限・色覚特性のある読者での隣接色の分離・
背景とのコントラスト）。全項目が通っている。

### 9 色目を作らない

カテゴリ配色は 8 色で打ち止めにし、`PALETTE.series(8)` は**例外を投げる**。
循環させた 9 色目は、色覚特性のある読者には既存の色と区別できない。
水準が多いときは上位を残して「その他」にまとめる。

### 散布図は 3 色まで

棒や折れ線では「隣り合う色」だけ区別できればよいが、散布図・PCA では
**すべての対が同時に目に入る**。4 色目で黄と橙が並び、その対は検証を通らない。

## 3. 日本語フォントに無い文字を図に描かない

IPAexGothic には **`≥` `≤` `✗` `µ`（MICRO SIGN）が無い。**
そのまま描いても例外は出ず、**黙って豆腐（□）になる。**

実際、SMD フォレストの凡例「|SMD| ≥ 0.1」が豆腐になっていた。
`viz._save()` がすべての図の文字を通して `≧ ≦ × μ` に置き換え、
`viz.missing_glyphs(fig)` がテストから「この図にフォントに無い文字が無いこと」を検査する。

`µ`（MICRO SIGN, U+00B5）と `μ`（GREEK SMALL MU, U+03BC）は別の文字で、
**辞書の単位（µmol/L、×10³/µL）には前者が混じっている。**

Phase 0 で CI に日本語フォントの確認を入れたのと同じ理由である。
**気づけない壊れ方は機械に見張らせる。**

## 4. レポートは症例レベルの値を既定で出さない

このレポートは HTML 1 枚でメールに乗る。受講者が自分のデータで作れば、
**仮名 ID であっても症例を特定しうる情報**が載る。

既定では監査の「該当例」も外れ値の「該当例」も件数だけにし、
`show_values=True` を**明示的に**渡したときだけ値を出す。
その場合はレポート自身が冒頭と末尾で「症例レベルの値を含む」と表示する。

構想 ver1.0 §13 のリスク表にあった項目を、そのまま実装に落とした。

## 6. HTML を組むときに踏んだ 2 つの罠

いずれも「見た目だけの問題」に見えて、実際には読めない表になる。
**どちらもブラウザで実際に描いて初めて分かった。**

### Jinja2 の autoescape が CSS を壊した

`{{ css }}` と書くと、`font-family: system-ui, -apple-system, "Hiragino Sans"` の
引用符が `&#34;` になり、**宣言ごと無効になって本文が明朝（Times New Roman）で
描かれていた。** `{{ css | safe }}` にする。
本文（利用者のデータ）のエスケープはそのまま維持する。

### クラス名が衝突した

ページ外枠の `.wrap`（`padding: 32px 20px 80px`）が、表のセルに付けた
`<td class="wrap">` にも当たり、**その行だけ高さが 33px → 135px に膨らんだ。**
長い説明文の入る行だけが妙に間延びして、文字が下にずれて見えた。
表のクラスには接頭辞を付けた（`t-wrap` / `t-num`）。

どちらも回帰テストで固定した。

## 7. 図の一覧

| 図 | 見るもの |
|---|---|
| 欠損の地図 | どの症例でどの列が同時に欠けるか |
| 連続変数の分布 | 中央値と形。二つ山なら別の集団が混ざっている疑い |
| カテゴリの内訳 | 例数の少ない水準（検定が不安定になる） |
| 相関 | 発散配色。似た動きの列が隣に来るよう並べ替え |
| 関連の強さ | 順次配色。型の違う列どうしも比べられる |
| 主成分 | 群の分離・施設差・外れ値の塊 |
| 目的変数との関係 | 回帰は散布図＋移動中央値、分類はクラス別分布 |
| 単変量 AUC | 0.5 からの距離。**ここで変数を選ぶと選択後推論の問題が起きる** |
| SMD フォレスト | train と test のバランス。|SMD| < 0.1 が目安 |
| 管理目標の達成率 | 群ごとの棒。境界値の扱いは表で確かめる |

`overview()` が一通り作り、**描けなかった図は理由を残して飛ばす**。
