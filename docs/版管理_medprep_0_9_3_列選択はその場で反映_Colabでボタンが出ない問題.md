## 1. きっかけ

> GROUP などを選択し終わる、もう一度同じセルを評価するのですか？（User）

**画面から読み取れない作りになっていた。** 二つ原因がある。

## 2. 原因① ボタンを押して初めて反映される作りだった

0.9.0 の選択画面は、ドロップダウンで選んだあと「この指定で進む」ボタンを
押して初めて `GROUP` などに入る作りだった。押さなければ何も起きない。
「選んだのに、次に何をすればよいのか」が分からない。

### 直し方

ドロップダウンを `observe` し、**選んだ瞬間に反映**する。
表示した直後にも一度当てはめるので、**推定した初期値（施設・日付 3 列）は
触らなくても効く**。`（指定しない / skip）` に戻せばその場で解除される。

画面には毎回こう出す。

```
◇ GROUP          = 施設   ← 指定があれば Table 2（群間比較）を作る
◇ OUTCOME / TASK = （指定なし） / （指定なし）
◇ SURVIVAL_DATES = ('観察開始年月日', 'event発生年月日', '観察打ち切り年月日')

★選んだ時点で反映される。このセルを実行し直す必要はない。★
   次は「◆ 2. 演習① まず全自動で走らせる」のセルを実行すること。
   選ばなくても先へ進める（群分け無しで走り、Table 1 だけが作られる）。
```

## 3. 原因② ★Colab でボタンが出ていなかった★

User の画面（Colab）では、ドロップダウンは出ているのに**その下のボタンが無い**。

```python
display(widgets.VBox(box), widgets.HBox([b_ok, b_no]), out2)   # ← これ
```

`display()` に**複数のウィジェットを並べて渡す**と、Colab では 2 つめ以降が
描画されないことがある。JupyterLab では出るので、こちらの手元では気づけない。

### 直し方

**1 つの箱にまとめて display する。**

```python
display(widgets.VBox([*box, b_no, out2]))
```

ボタンは「すべて指定しない（skip）」の 1 つだけにした
（選んだ時点で反映されるので「進む」ボタンは要らなくなった）。

> 教訓: **Colab と JupyterLab でウィジェットの描画は同じではない。**
> 手元で出たからといって Colab で出るとは限らない。
> ウィジェットは 1 本の木にまとめて 1 回で display する。

## 4. 検証

- ウィジェットを**プログラムから操作**して確かめた（ボタンを押さずに値を変える）
  - 表示直後: `GROUP = 施設`、`SURVIVAL_DATES` の 3 列が入っている
  - `GROUP` を「性別」に変更 → その場で `GROUP = 性別`
  - `OUTCOME` を「糖尿病」に変更 → `TASK = classification` を自動提案
  - `GROUP` を skip に戻す → `GROUP = ''`
  - skip ボタン → すべて解除
  - display に渡ったのは **VBox 1 つだけ**で、その中に
    ドロップダウン 6 + ボタン 1 + Output 1 が入っている
- `ruff` 通過、**NB Ver1_8_3 を nbclient で頭から通した**（エラー 0、90 セル）

## 5. 使い方（受講者向けのまとめ）

1. 「4) データの入力」でボタンを押してデータを読む
2. すぐ下に出る欄で GROUP などを選ぶ ── **選んだ時点で反映される**
3. そのまま「演習①」のセルへ進む ── **同じセルを実行し直す必要はない**

環境変数に `GROUP = '施設'` と書いてあれば、この欄は出ない（**書いたほうが強い**）。
