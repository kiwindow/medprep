## 2. `DROP_EMPTY_ROWS` ―― 既定は False

```python
DROP_EMPTY_ROWS = False        # 環境変数セル
rep = mp.autoprep(df, ..., drop_empty_rows=DROP_EMPTY_ROWS)
```

★既定では 1 行も削除しない。★ 行を削除すると症例数と並びが変わり、
元のデータと症例ごとに `axis=1` で結合し直せなくなる。
それでも**全てのセルが空欄の行は症例ですらない**ので、消したい人が選べるようにした。

### 黙っては消さない

| | 段の表 | 警告 | ファイル |
|---|---|---|---|
| `False`（既定）・空行あり | **「★3 行ある（削除していない）★ 消すなら DROP_EMPTY_ROWS = True」** | 出す | ― |
| `False`・空行なし | 「しない（既定）。該当する行も無い」 | ― | ― |
| `True` | 「3 行を削除した（603 行 → 600 行）」 | 出す | **「削除した行」シート** |

「削除した行」シートの中身:

| 元の行 | Excel の行 | 理由 |
|---|---|---|
| 100 | 102 | 全てのセルが空欄 |
| 101 | 103 | 全てのセルが空欄 |
| 102 | 104 | 全てのセルが空欄 |

`Excel の行` は**見出しが 1 行目にある前提**の行番号である。
`元の行` だけだと、Excel を開いたときにどこを見ればよいか分からない。

シートの並びは **まとめ / （削除した行）/ 外すのが望ましい症例 / 解析から外す列**。
「削除した行」は `True` のときだけ作る。
★選んでいないのに空のシートがあると、消えたのかと人が心配する。★

「まとめ」では**一番上**に置く。★本当に削除したものだけが取り返しがつかない。★

### 空とみなすもの

`NaN` のほか、**空文字と空白だけの文字列（半角・全角）**も空とみなす。
`isna()` だけで見ると、Excel で「見た目は空」の行が**残ってしまう**。

## 3. ★見つかった不具合★ 読み込みが、表の途中の空行を黙って消していた

`read_any` の `_drop_empty` が `dropna(how="all")` で**無条件に**空行を消していた。
これでは `drop_empty_rows=False`（既定）が意味を持たない。
**既定が効かない既定は嘘である。**

扱いを二つに分けた。

| どこの空行 | 扱い | なぜ |
|---|---|---|
| **表の末尾**にぶら下がったもの | 落とす（落としたと言う） | Excel の「使った範囲」の名残り。症例ではない |
| **表の途中**にあるもの | **残す**（あると言う） | 入力の事故。消してよいかは人が決める |

`False` のまま走らせると、空行はそのまま残る。そのとき何が起きるかも教材になる。

- 品質監査が **「重複: 全列が一致する行がある」**を出す（空行同士が一致する）
- 生存時間の段が **「イベント日・打ち切り日ともに空欄」**として `除外推奨` の印を付ける

**空行を残すと下流がこう騒ぐ**、ということ自体が見どころである。

## 4. 演習①の章立て（Ver2_5）

```
◆ 2. 演習① まず全自動で走らせる
  ## 1) 自動前処理の実行
  ## 2) 行の処理
     ### 行の処理の一覧
  ## 3) 列の処理
     ### 入力が二値の列を 0/1 に直した ―― 1 がどちらかを列名で示す
  ## 4) 出力データ ―― ４つのファイル
     ### ①〜④ は、どれも 1 枚のシートではない
     ### 欠損指示子を特徴量にしない理由
     ### 段ごとに、何が足されるか
     ### データ以外に保存されるもの
  ## 5) 分析のレポート
```

> **番号について** ―― ご指示では「列の処理」と「出力データ」がどちらも 3) でした。
> 通し番号になるよう、出力データ = 4)、分析のレポート = 5) としています。

### 4 段階に書き直した

「3 段階」と書いてあったが、実際には**元データを含めて 4 つ**書き出している。

| # | ファイル | 行 | 列 |
|---|---|---|---|
| ① | 元データ | 元と同じ | 全列 |
| ② | 掃除済みデータ | 元と同じ<sup>※</sup> | 全列＋派生列 |
| ③ | 解析用データ | 元と同じ<sup>※</sup> | 落とす列を除く |
| ④ | 前処理済み_train / _test | ★部分集合★ | 特徴量のみ |

<sup>※</sup> `DROP_EMPTY_ROWS = True` のときだけ減る。

★①〜④ はどれも 1 枚のシートではない。★ 現物に合わせて書いた。

| ファイル | シート |
|---|---|
| ① 元データ | 1 枚だけ |
| ② 掃除済みデータ | データ / 列の扱い / 減らしたもの |
| ③ 解析用データ | データ / 0と1の対応 |
| ④ 前処理済み | 標準化後 / 生の値 / 欠損値の位置 |

「データ以外に保存されるもの」の表も、`table/` `model/` `figure/` `report/` の
現物（`prep_tables.xlsx`・`Table1_2.docx`・`table1_詳細.xlsx`・
`medprep_version.txt` など）に合わせて書き直した。
