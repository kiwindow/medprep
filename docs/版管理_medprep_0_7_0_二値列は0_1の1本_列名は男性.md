## 1. きっかけ

> 性別で男/女、男性/女性、M/F などとある場合は、男性を 1 にし、女性を 0 にし、
> 項目名は男性にしてください。つまり、one-hot encoding して下さい。（User）

0.6.0 までは、性別も施設も**まとめて** `OneHotEncoder(drop="first")` に渡していた。

## 2. 何が問題だったか

水準が 2 つの列は、one-hot にしても**列は 1 本にしかならない**。
問題は「列が何本になるか」ではなく、**どちらの水準が 1 になるか**である。
`drop="first"` は、それを **sklearn の辞書順**で決める。

| 元の記録 | 0.6.0 が作る列 | 1 が指すもの |
|---|---|---|
| 男 / 女 | `性別=男` | 男 |
| M / F | `性別=M` | M |
| 男性 / 女性 | `性別=女性` | **女性**（!） |

**同じ意味の列が、書き方によって別名になる。**
しかも `性別=女性` は 1 が女性である。施設ごとにエクスポートの書き方が違う
（第3回の合成データがまさにそう作ってある）以上、施設をまたいで結合した
瞬間に破綻し、係数の符号が施設によって逆になる。

さらに one-hot は**カテゴリ集合を fit で学習する**ので、train に片方の水準しか
現れなければ test の水準を扱えない。二値列にその学習は要らない。

## 3. 直し方

### 3.1 `BinaryMapper`（`pipeline.py`）

`Schema.infer()` は二値列を見つけたとき、どの対応表に一致したかを
`ColumnSpec.value_map` に残している（`BINARY_MAPS`）。**それを使えばよい。**

```python
elif sp.role == BINARY and sp.value_map:
    binmaps[c]  = dict(sp.value_map)          # 男→1、女→0
    binnames[c] = binary_output_name(c, sp.value_map)   # → 男性
```

`ColumnTransformer` の枝を 1 本足す。

```python
("bin", Pipeline([
    ("map", BinaryMapper(mappings=binmaps, names=binnames)),
    ("imp", SimpleImputer(strategy="most_frequent")),
]), binary)
```

`BinaryMapper` は**何も学習しない**。対応表は固定なので、
train に女性しか居なくても test の男性は 1 になる。
対応表に無い値（表記ゆれ・想定外の水準）は欠損にして後段の補完に渡す。
**例外にはしない**（1 例の表記ゆれで全体が止まるのは教材として最悪である）。

### 3.2 `binary_output_name()`（`schema.py`）

列名は**意味で**決める。1 側の水準名が、それだけで意味の通るものだけを採る。

```python
BINARY_POSITIVE_NAME = {"男": "男性", "男性": "男性", "m": "男性", "male": "男性",
                        "死亡": "死亡"}
```

| 元の列 | 対応表 | 作る列 |
|---|---|---|
| 性別 | 男:1 / 女:0 | **男性** |
| 性別 | M:1 / F:0 | **男性** |
| 性別 | 男性:1 / 女性:0 | **男性** |
| 性別 | Male:1 / Female:0 | **男性** |
| 転帰 | 生存:0 / 死亡:1 | **死亡** |
| 糖尿病 | あり:1 / なし:0 | 糖尿病（そのまま） |
| HBs抗原 | 陽性:1 / 陰性:0 | HBs抗原（そのまま） |

★`あり` を列名にしない理由★ ── 列名が「あり」では**何の列か分からなくなる**。
1 側の水準名が意味を持たない列は、元の列名を残すほうが読める。

出力名がほかの列とぶつかるとき（既に `男性` という列がある等）は元の列名に戻す。

### 3.3 基準水準の報告

`reference_levels()` は二値列についても **0 とした水準**を返す。
HTML レポートの表に「作った列」の欄を足した。

```
元の列    基準（0 とした水準）   作った列
性別      女                   男性
施設      A院
```

水準が 3 つ以上の列（施設 A院/B院/C院/D院）は**これまでどおり one-hot** である。
