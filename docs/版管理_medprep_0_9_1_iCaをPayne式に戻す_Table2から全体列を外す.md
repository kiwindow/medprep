## 2. iCa を Payne 式（条件つき）に戻した

0.9.0 では依頼文の式をそのまま読み、**無条件**に `Ca + (4 − Alb)` としていた。
しかし日本の運用では **Alb ≥ 4.0 では補正しない**。

```
Alb < 4.0   iCa = Ca + (4 − Alb)
Alb ≥ 4.0   iCa = Ca（実測のまま）
```

無条件にすると、Alb 4.5 の症例で iCa が実測 Ca より **0.5 低く**なる。
低アルブミン血症で見かけ上低く出る Ca を補正するのが目的なので、
Alb が十分あるときに下方へ動かす理由はない。

`quality.audit` の検算（「補正Ca が Payne 式と一致しない」）も同じ式に戻した。

★Alb が欠測なら算出不能（NaN）★ という扱いは 0.9.0 と同じである。
`np.where(np.nan < 4.0, ca + (4.0 - alb), ca)` は NaN の比較が False に落ちるため、
そのまま書くと **補正されていない Ca が iCa として黙って混ざる**。必ず mask する。

実測での確認（合成データ）:

| Ca | Alb | iCa |
|---|---|---|
| 9.4 | 4.3 | **9.4**（補正しない） |
| 8.9 | 3.7 | 9.2 |
| 8.3 | 4.2 | **8.3**（補正しない） |
| 8.7 | 3.4 | 9.3 |

## 3. Table 2 から「全体」の列を外した

gtsummary の例に引かれて `Overall` 列を入れていたが、**2 枚に分けた意味が無くなる。**

```
Table 1 … 全体            ← 全体はこちらの役目
Table 2 … 群間比較        ← 群ごとの列と p 値だけ
```

横にも 1 列ぶん短くなるので、群が多いときに読みやすくなる。
N は各群の見出し（`A院 (N = 230)`）に入っているので、情報は落ちない。
脚注の ¹（平均値 ± 標準偏差 [最小値, 最大値]；n (%)）は各群の見出しに付け直した。

水準が 3 つ以上のカテゴリの「—」も、群の数ぶんだけに減らした。
