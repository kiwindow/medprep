## 2. 透析年数

`derive_vintage()` を足し、**日付を解釈したあと**に走る段を 1 つ置いた
（文字列のままでは引き算ができないので、掃除の段では作れない）。

```
透析年数 = floor((その検査の日 − 透析開始年月日) / 365.25)
```

終了日は **検体採取日 →（無ければ）観察開始年月日** の順で選び、
**どちらを使ったかを必ず注記に出す。**

★今日の日付では代用しない。★ 走らせた日によって値が変わる列を黙って混ぜたら、
同じデータから二度と同じ結果が出なくなる。**終了日が無ければ作らない。**

- 0 年は「導入後 1 年未満」を意味する
- 導入日が空欄・解釈不能、開始 > 終了 の症例は NaN
- 辞書に `vintage_y`（透析年数、単位 年、0〜60）を追加。月単位の `vintage` とは別項目
  （別名 `透析歴(年)` は `vintage` から外して `vintage_y` に移した。衝突するため）

合成データは **`透析歴_月` を渡すのをやめ、`透析開始年月日` を渡す**ようにした。
実務のデータは導入日が入っていて、年数は入っていない。**年数は作らせる。**
導入日が空欄の症例も汚れとして入れてある。

## 3. CRP

- 列名を **`CRP定量`** にした。`C反応性蛋白(CRP)定量` は長すぎて、Excel で
  切れると読めない。辞書の別名に `CRP定量` を足してあるので、どちらでも同定できる。
- **Excel の小数は最低 2 桁**にした。0.10.0 の桁数計算は
  「いちばん小さい非ゼロの値 + 1 桁」だったので CRP が 3 桁になっていた。
  下限を 2 桁に変え、CRP は `0.00`（0.05 → 「0.05」）で書かれる。

| 列 | 書式 |
|---|---|
| CRP定量 | `0.00` |
| アルブミン(Alb) | `0.00` |
| duration | `0.000`（0.003 が 0.00 に丸まらないように） |
| 年齢・透析年数 | `0`（整数） |

## 4. 施設 ―― 前処理済みを 2 枚組にした

施設そのものは名義尺度のまま扱われている（`解析用データ.xlsx` は `A院` のまま、
`schema` の役割は `group`、Table 2 の群分けにも使える）。
**読めなくなっていたのは `前処理済み_*.xlsx`** である。
モデルに渡す行列なので `施設=B院` のダミーになり、数値は z 値になる。

そこで **1 つのブックに 2 枚**入れることにした。

| シート | 中身 |
|---|---|
| **標準化後** | モデルに渡す行列（従来どおり） |
| **生の値** | 同じ症例・同じ列を、標準化する前の値で並べたもの |

「生の値」では `施設` は `A院` のまま、`透析時間(hr)` は 3.75 のまま出る。
**群間比較も、値の目視確認も、こちらでできる。**

## 5. 元データも保存する

`data/元データ.xlsx` に、前処理前の手を触れていないデータを保存する。
**掃除の前と後を突き合わせられないと、「この値はもともとこうだったのか、
機械が直したのか」が分からなくなる。**

`data/` の中身は 5 つになった。

```
元データ.xlsx          手を触れていない元のまま
掃除済みデータ.xlsx     値を掃除し日付を解釈（全列・全行）
解析用データ.xlsx       落とす列を除き、二値を 0/1 に（全行）
前処理済み_train.xlsx   標準化後 ／ 生の値 の 2 枚組
前処理済み_test.xlsx    同上
```
