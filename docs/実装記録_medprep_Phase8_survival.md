## 2. 主目的：Cox の「黙って減る n」を見張る

`CoxPHFitter` は共変量に欠測のある症例を**黙って捨てる**（完全ケース解析）。
共変量を 1 本足しただけで n が 578 から 508 に減り、
それに気づかないまま「ハザード比が変わった」と解釈するのは、
**実データの解析で最も多い事故のひとつ**である。

`cox()` は fit の前後で例数とイベント数を数え、どの列の欠測が多いかまで報告する。

```
Cox 比例ハザード回帰  n = 508、イベント = 203、共変量 = 6、EPV = 33.8
欠測により除外: 70 例（うちイベント 24 件）

[警告] 共変量の欠測により 70 例（イベント 24 件）が解析から落ちた（578 → 508）。
       欠測の多い列: Alb: 49、vintage: 15、年齢: 3。
       Cox は完全ケースだけで推定するので、共変量を足すと n が黙って減る。
       補完するか、その変数を外すかを決めること
```

## 3. 比例ハザード違反は「どうするか」まで言う

`proportional_hazard_test` は p 値を返すが、**p 値だけでは何もできない。**

```
[警告] 比例ハザード仮定に違反している変数がある（['logCRP']）。
       ハザード比が『時間によらず一定』でないので、1 つの HR で要約できない。
       (1) その変数で層別する cox(strata='...')、
       (2) 時間依存項を入れる、
       (3) RMST に切り替える rmst(by='...')、のいずれかを選ぶこと
```

RMST（制限付き平均生存時間）を用意してあるのはこのためである。
ハザード比は「差が時間によらず一定」を前提にするが、RMST は
「時点 τ までの平均生存時間」なので前提が要らず、単位も直感的（年・日）。
打ち切りが無ければ `mean(min(T, τ))` と一致することをテストで固定した。

合成データでは実際に logCRP が PH 違反（p=0.0445）になり、
`run_e2e.py` が自動で RMST を出すところまで通った。

## 4. log-rank trend test を自前で持つ

lifelines に傾向検定が無い。順序のある群（病期・stage）では、
多群 log-rank より傾向検定のほうが検出力が高く、臨床的にも問うべき仮説に近い。

```
U = Σ_j s_j (O_j − E_j),  V = Σ_t d(n−d)/(n−1)[Σ_j s_j² n_j/n − (Σ_j s_j n_j/n)²]
χ² = U²/V（自由度 1）
```

正しさは **「2 群でスコア (0,1) を与えると通常の log-rank と一致する」** ことで固定した。
実測で **小数点以下 10 桁まで一致**した。

```
trend    9.4769455937  p=0.002080701
logrank  9.4769455937  p=0.002080701
```

順序の無い群（施設名など）に当てはめないよう、結果に注記を付ける。

## 5. Kaplan-Meier 図の既定値を直した

lifelines の既定のまま描くと、**4 群で曲線が細い帯に潰れて読めない。**
at-risk 表が At risk / Censored / Events の 3 行 × 4 群 = 12 行になるためである。

直したこと：

* at-risk 表は **「At risk」の行だけ**
* **図の高さを群数に合わせて広げる**（at-risk 表は群の数だけ縦に伸びる）
* **信頼区間の帯は 2 群までを既定に**（3 群以上は重なって曇りガラスになる。`ci=True` で描ける）
* 打ち切り記号を小さく（`ms=5, alpha=0.6`）
* 凡例を左下に固定
* フォレストプロットの対数軸は素の数（0.5, 1, 2）で目盛る。
  matplotlib の既定（`4×10⁻¹`）はハザード比としては読めない
* `p=<0.001` という読みにくい書き方をやめ、`p<0.001` と書く

## 6. NR（not reached）の扱い

生存期間中央値に到達しなければ **NR** と書く。NaN で流さない。
これは「生存が良い」ではなく **「追跡期間が足りない」という事実**である。

ここで 1 つ罠を踏んだ。最初の実装は表示文字列に `"NR"` が含まれるかで判定していたため、
**`4.6 [3.0–NR]`（中央値は出たが信頼区間の上限が NR）を「到達せず」と誤判定**していた。
合成データで A院・C院・D院 の 3 群が到達せずと表示され、実際は D院 だけだった。
値（`np.isfinite(med)`）で判定するよう直し、回帰テストで固定した。

追跡期間中央値は **reverse Kaplan-Meier 法**（イベントと打ち切りを入れ替えて推定）で出す。
生存期間中央値と混同しないよう注記を付ける。

## 7. Cox のその他の見張り

| 見張るもの | 動作 |
|---|---|
| EPV < 10 | 警告（過学習が強く疑われる。罰則つき Cox を提案） |
| カテゴリ共変量 | 自動でダミー化し、**基準水準を必ず記録**（基準が分からなければ HR は読めない） |
| 定数・分散 0 の共変量 | 理由つきで外す（lifelines の分かりにくい収束エラーになる前に） |
| 水準が 10 個を超えるカテゴリ | 外す |
| 信頼区間が極端に広い変数 | 完全分離の兆候として警告 |
| lifelines の `ConvergenceWarning` | **握り潰さず結果に取り込む**（標準エラーに流れて消えるため） |
| 逐次選択 | **使わない。** 既定は「単変量で p<0.10 → 多変量」で、これも選択であることを注記する |
