## 2. 表を出すだけでは足りない

医学論文の Table 1 は、数字より先に **「なぜその検定なのか」** を問われる。
`describe` は検定を自動で選び、**選んだ理由を「判定の根拠」列に残す。**

```
CRP [mg/dL]  Mann-Whitney U 検定  Cliff's δ = 0.016
    → 2群・非正規。Shapiro-Wilk p=8.74e-40 < 0.05 で棄却され、歪度 7.63（|skew| ≥ 0.5）も大きい
年齢 [歳]      Welch の t 検定      Hedges' g = 0.010
    → 2群・正規。Shapiro-Wilk p=0.089 ≥ 0.05。歪度 -0.19。分散の等質性を仮定しない Welch を既定にする
```

### 検定の自動選択

| 状況 | 検定 | 事後比較 |
|---|---|---|
| 連続・2群・正規 | Welch の t 検定 | — |
| 連続・2群・非正規 | Mann-Whitney U | — |
| 連続・3群以上・正規 | 一元配置分散分析 | **Tukey HSD** |
| 連続・3群以上・非正規 | Kruskal-Wallis | **Dunn（Holm 補正）** |
| カテゴリ | χ²（期待度数 < 5 が 2 割超なら **Fisher 正確検定**に自動切替） | — |
| 対応あり（`paired_by=`） | 対応のある t / Wilcoxon 符号付順位 | — |

Dunn 検定は scipy に無いので、同順位補正つきで自前実装した。

### 効果量と SMD を必ず併記する

p 値は例数で動く。効果量は動かない。
Hedges' g（小標本補正つき）／Cliff's δ／η²／ε²／Cramér's V を項目ごとに出す。
群間バランスは SMD で見る。多水準の SMD は Yang & Dalton 法、3 群以上は対ごとの最大値。

### 多重比較

Table 1 は列数ぶんの p 値を出すので、**BH の q 値を必ず併記**する。

## 4. 正規性は「検定の棄却」だけでは決めない

Shapiro-Wilk を n=600 に当てると、実用上どうでもよい歪みでも p<0.05 になる。
検定だけで決めると Table 1 はほぼ全項目が 中央値[Q1,Q3] になり、
**読みにくくなるだけで何も改善しない。**

ここで決めたいのは「厳密に正規分布か」ではなく
**「平均と中央値のどちらがこの分布を忠実に代表するか」**である。

したがって：

* 検定が棄却し、**かつ** 歪度 |skew| ≥ 0.5 または過剰尖度 ≥ 1.0 → 非正規
* 検定は棄却するが形は素直 → **平均(SD) のままにする**（理由を書く）
* n < 20 → 検定に検出力が無いので形だけで判断する

どちらの基準で決めたかは必ず根拠に書き出す。回帰テストで固定した
（`test_large_n_with_a_tiny_deviation_stays_normal`）。

## 5. Table 1 の p 値には解釈上の注意を必ず添える

```
【Table 1 の p 値について】無作為割付なら、ベースラインの群間差は偶然によるものと
分かっているので p 値に意味は無い。観察研究なら、例数が増えるだけで p は小さくなる。
群間バランスは p ではなく SMD（目安 |SMD| < 0.1）で評価すること。
```

この注記は `notes` に必ず入る。Excel 出力にも「注記」シートとして付く。

## 8. 書いていて踏んだ罠

```python
c.effect = cramers_v(x, y) or float("nan")     # ← 誤り
```

関連がまったく無いとき Cramér's V は **0.0** を返す。Python では 0.0 が偽なので、
`or` で既定値を与えると「算出できなかった」ことにされてしまう。
実際、糖尿病の行で効果量が空欄になっていた。`None` かどうかで判定するよう直し、
回帰テストで固定した。

あわせて 2 点：

* Kruskal-Wallis の ε² は群間差が偶然より小さいと負になる。
  効果量の負値は「小さい」ではなく「逆向き」と読まれるので 0 に丸めた。
* 非正規の根拠に「歪度…・過剰尖度…も大きい」と両方書いていたが、
  尖度が小さい場合に文言と数字が食い違う。**実際に効いた基準だけを書く**ようにした。
