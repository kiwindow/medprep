# 第3回「データの前処理」スライド

`第3回_データの前処理_ver1_0.pptx`（20 枚）を組み立てるスクリプト。

```bash
uv pip install python-pptx
python examples/slides/build_slides.py
```

## 体裁

既存教材（`HowToSetUpPC.pptx`）から採った配色・座標に合わせてある。

| 要素 | 大きさ | 色 |
|---|---|---|
| 大見出し（スライドタイトル） | 26pt | `#13233F` |
| 中見出し（カード見出し） | 17〜18pt | `#1565C0` |
| 本文 | 14〜15pt | `#13233F` |
| eyebrow ラベル | 14pt | `#1565C0` |
| 注記 | 13pt | `#5A6B84` |

**すべて Bold。** フォントは Yu Gothic（latin / ea / cs をすべて明示）。

## 高さは目分量で置かない

`auto_h()` / `code_h()` が本文の量から箱の高さを計算し、`card()` / `code()` /
`callout()` / `table()` が**次を置く位置（下端）を返す**。
それを積み上げて配置するので、文言を直しても崩れない。

見積りには**折り返し 1 行ぶんの余裕**を入れてある（`cpl * 0.92`）。
Yu Gothic と代替フォントでは折り返し位置が変わり、1 行ずれるためである。

`**強調**` は**色の変化**になる（すべて Bold なので、太さでは強調を表せない）。

## 版を上げるとき

**既存の pptx を上書きしない。** 版番号を変えて保存する。

* 大きな修正 → `ver2_0`, `ver3_0`, ...
* 中程度の修正 → `ver1_1`, `ver1_2`, ...
* ごく僅かな修正 → `ver1_0_1`, `ver1_0_2`, ...

`build_slides.py` の末尾の出力ファイル名を変えること。
